## 2. Run it locally

1. `npm ci`, then `npm run db:generate` after pulling a schema change (F-61), then `npm run db:migrate` before `npm run db:seed` on a fresh database (F-49).
2. Start the dev server: `npm run dev`. Keep that window open.
3. Start a cloudflared quick tunnel to the dev server's port in a second window. The URL changes on every restart, and the tunnel died once (ERR_NAME_NOT_RESOLVED).
4. In the PayPal developer dashboard (sign in with the owner's developer account, not the sandbox buyer; F-66), open the KeepMore Spike app and set the webhook URL to the new tunnel URL plus `/api/webhooks/paypal`. Do this after every tunnel start (F-70, F-58).
5. To check deliveries, open Webhook Events and select KeepMore Spike. The default view is Default Application (F-74).
6. For checkout, leave the PayPal popup to close itself. Closing it by hand skips `onApprove` and nothing is captured (F-67).
7. **Never read, print, copy or commit `.env` or `dev.db`.** Placeholders belong in `.env.example` only. Do not put tunnel URLs, webhook ids or tokens in docs, logs or commits.
8. Start `claude` before pasting a prompt (F-62). Ask for English output only (F-63). Give one-line commands (F-65).
